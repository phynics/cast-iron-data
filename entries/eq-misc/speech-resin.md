**Price** 410 gp; **Weight** -\
**Category** Alchemical Tools

Chewing this gummy substance grants you 1d4 uses of
[alchemical inspiration](ref/misc/alchemical-inspiration) that can be used only on Charisma-based
skill checks. This benefit lasts for 1 hour, during which you must roll all Wisdom-based skill
checks twice and take the worse result.

**Construction:** Craft (Alchemy) DC 25
