**Price** 40 gp; **Weight** 4 lbs.\
**Category** Tools

This kit contains all the butchers' tools, preservatives, and desiccants necessary to turn a dragon
corpse into usable items. It provides the user with a +2 circumstance bonus on all Heal and Craft
skill checks made to harvest dragoncraft materials and create dragoncraft items.
