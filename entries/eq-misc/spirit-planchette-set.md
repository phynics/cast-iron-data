**Price** 25 gp; **Weight** 5 lbs.\
**Category** Adventuring Gear

A spirit planchette is typically found in a wooden case along with a thin wooden board printed with
numerous letters and numbers. Nonmagical versions of these divination tools can be purchased in
curiosity shops; while these items can be used as alternative components for
[augury](ref/spell/augury) spells, only
[magical spirit planchettes](ref/magic-wondrous/spirit-planchette) allow users to communicate with
the other side.
