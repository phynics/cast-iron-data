**Entrepreneur (Ex)**

**Ability:** The vigilante can use the selected skill to earn money as if he were using a Profession
skill. If he selects Perform or Profession, the vigilante instead gains the skill unlock powers for
those skills as appropriate for his number of ranks in that skill.

**Choice:** Select any one Intelligence-, Wisdom-, or Charisma-based skill other than Perception or
Use Magic Device.

**Special:** If he has the [social grace](ref/soctalent/social-grace) social talent, he can apply
this benefit to all skills selected with the _social grace_ talent.
