**Sources:** PRPG Core Rulebook pg 11

This value represents how skilled a [creature](ref/misc/creature) is at performing a
[combat maneuver](ref/misc/combat-maneuver). When attempting to perform a combat maneuver, this
value is added to the character's d20 roll.
