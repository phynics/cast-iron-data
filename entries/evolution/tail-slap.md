**Tail Slap (Ex)**

**Ability:** An eidolon can use its tail to bash nearby foes, granting it a
[tail slap attack](ref/umr/natural-attacks). This attack is a secondary attack. The tail slap deals
1d6 points of damage (1d8 if Large, 2d6 if Huge).

**Prereq:** [Tail](ref/evolution/tail)

**Special:** This evolution can be selected more than once, but the eidolon must possess an equal
number of the _tail_ evolution.
