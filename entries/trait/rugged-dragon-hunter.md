**Type:** Social

**Benefit:** You gain a +2 trait bonus on [Survival](ref/skill/survival) checks to track dragons. If
you have the [favored terrain](ref/ability/favored-terrain) class ability, add a +1 bonus to check
for skills affected by this ability, as long as you're using these skills in regards to a dragon.
