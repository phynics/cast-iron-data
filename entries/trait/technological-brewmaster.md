**Region:** Numeria

**Flavor:** You have learned the secret of creating potions using advanced scientific techniques so
strange that some might consider them alien.

**Benefit:** When brewing a potion, you can increase its base creation cost by 10% to brew it in
half the normal amount of time. This trait does not grant the ability to brew potions.
