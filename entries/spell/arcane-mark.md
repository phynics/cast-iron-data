::: statblock
title = "Spell statistics"
School: universal
Level: 0: Arcanist, Magus, Psychic, Shaman, Sorcerer, Summoner, Unchained Summoner, Witch, Wizard
Casting time: 1 standard action
Components: V, S
Range: touch
Duration: permanent
Saving throw: none
Spell resistance: no
Effect: one personal rune or mark, all of which must fit within 1 sq. ft.
:::

This spell allows you to inscribe your personal rune or mark, which can consist of no more than six
characters. The writing can be visible or invisible. An _arcane mark_ spell enables you to etch the
rune upon any substance without harm to the material upon which it is placed. If an invisible mark
is made, a detect magic spell causes it to glow and be visible, though not necessarily
understandable.

[See invisibility](ref/spell/see-invisibility), [true seeing](ref/spell/true-seeing), a
[gem of seeing](ref/magic-wondrous/gem-of-seeing), or a
[robe of eyes](ref/magic-wondrous/robe-of-eyes) likewise allows the user to see an invisible _arcane
mark._ A [read magic](ref/spell/read-magic) spell reveals the words, if any. The mark cannot be
dispelled, but it can be removed by the caster or by an [erase](ref/spell/erase) spell.

If an _arcane mark_ is placed on a living being, the effect gradually fades in about a month.

_Arcane mark_ must be cast on an object prior to casting
[instant summons](ref/spell/instant-summons) on the same object (see that spell description for
details).
