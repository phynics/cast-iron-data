## Magnetism (Sp)

**Element:** air, earth

**Type:** utility (Sp)

**Level:** 3

**Burn:** 0

**Prerequisite:** [magnetic infusion](ref/kinetic/magnetic-infusion)

**Saving throw:** none

**Spell resistance:** yes

**Source:** Elemental Master's Handbook/22

You can push and pull metal objects using magnetism. This functions as
[telekinetic maneuvers](ref/kinetic/telekinetic-maneuvers) but you can make only
[bull rush](ref/rule/bull-rush) and [drag](ref/rule/drag) combat maneuvers, and can do so only
against metal objects or creatures. If you use this ability on an attended metal object, you must
exceed the creature's CMD as normal, and if it's holding the object, it must drop it or this ability
pushes or pulls the creature.
