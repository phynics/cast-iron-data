**Sources:** Ultimate Intrigue pg 250\
**Aura** faint illusion; **CL** 5th\
**Slot** head; **Price** 650 gp; **Weight** -

A wearer can remove this mask as a move action to change his appearance as if using
_[disguise self](ref/spell/disguise-self)._ The effect persists for 10 minutes. A
[vigilante](ref/class/vigilante) can instead remove a quick-change mask to switch his identity as a
move action. If the mask is used in this way, the effect functions just like changing identities
normally (except faster), and doesn't have a limited duration. Regardless of which way he is using a
quick-change mask, the user can attempt a [Bluff](ref/skill/bluff) check to create a diversion so he
can use [Stealth](ref/skill/stealth) as part of the same move action he uses to activate the mask.
The mask dissolves when used.

### Construction

**Requirements** [Craft Wondrous Item](ref/feat/craft-wondrous-item),
[disguise self](ref/spell/disguise-self), [eagle's splendor](ref/spell/eagles-splendor),
[prestidigitation](ref/spell/prestidigitation); **Cost** 325 gp
