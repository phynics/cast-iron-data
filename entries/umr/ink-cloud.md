## Ink Cloud (Ex)

Some cephalopods can emit a spherical cloud of ink once per minute as a free action while
underwater. This cloud provides [total concealment](ref/rule/concealment). The radius of the ink
cloud is included in the monster's description. The ink persists for 1 minute.

**Format**

**Details:** ink cloud (5-ft. radius)

**Location**

**Details:** Defensive Abilities
