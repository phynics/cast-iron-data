### Class Skills

The Commoner's class skills are [Climb](ref/skill/climb) (Str), [Craft](ref/skill/craft-any) (Int),
[Handle Animal](ref/skill/handle-animal) (Cha), [Perception](ref/skill/perception) (Wis),
