**Sources:** PRPG Core Rulebook pg 449

**Hit Die:** d8.

### Class Skills

The Aristocrat's class skills are [Appraise](ref/skill/appraise) (Int), [Bluff](ref/skill/bluff)
(Cha), [Craft](ref/skill/craft-any) (Int), [Diplomacy](ref/skill/diplomacy) (Cha),
[Disguise](ref/skill/disguise) (Cha), [Handle Animal](ref/skill/handle-animal) (Cha),
[Intimidate](ref/skill/intimidate) (Cha), Knowledge (all) (Int), Linguistics (Int), Perception
(Wis), Perform (Cha), Profession (Wis), Ride (Dex), Sense Motive (Wis), Swim (Str), and Survival
(Wis).

**Skill Points at each Level:** 4 + Int modifier.
