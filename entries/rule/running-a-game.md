A roleplaying game is only as good as its GM. The GM sets the tone for the game, keeps the action
moving, adjudicates situations, and tailors the storyline to the player's tastes. In this section,
you'll find all the information you need on how to run the best game you possibly can, from tips and
tricks to the tools of the trade, plus primers on avoiding common problems, the math behind the
game, and how to design different types of adventures.
