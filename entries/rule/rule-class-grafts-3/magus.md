The magus blends weapon training and magic to become an effective master of both.

**Required Array:** Expert.

**Statistics Adjustments:** Increase Fortitude saving throw bonus by 2; options-magic weapon,
secondary magic, spell combat, one magic.

**CR 1:** Options-spellstrike.

**CR 3:** Replace secondary magic with spellcasting (as if CR 2); options-spellstrike, one combat.

**CR 6:** Replace secondary magic with spellcasting (as if CR 4); options-combat casting,
spellstrike, one combat.

**CR 9:** Replace secondary magic with spellcasting (as if CR 6); options-combat casting,
spellstrike, one combat.

**CR 12:** Replace secondary magic with spellcasting (as if CR 8); options-combat casting,
spellstrike, one combat, one magic.

**CR 15:** Replace secondary magic with spellcasting (as if CR 10); options-combat casting, mage
punisher, spellstrike, one combat, one magic.

**CR 18:** Replace secondary magic with spellcasting (as if CR 12); options-combat casting, mage
punisher, spellstrike, two combat, one magic.

**Suggested Ability Modifiers:** Intelligence, Strength, Dexterity.

**Suggested Options:** Dodge expert, improved combat maneuver, magic attack (melee), metamagic
spell, mobile attack (melee).
