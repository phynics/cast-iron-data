**Sources:** Ultimate Equipment pg 365

Treasure of this type represents the typical gear that might be carried by a creature that
frequently finds itself in combat without the aid of spells or magic. These rewards include coins
only if needed to round out the total value to an easily used number. The individual items included
are determined by referring to other tables in this section. The specific table used is specified by
the reward. Note that the value of some types of armor and weapons can significantly increase the
value of some low-level rewards.
