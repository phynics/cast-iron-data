Whether as a place to rest between adventures or the setting of an entire campaign, cities offer the
PCs a vast number of options and the potential to draw unanticipated elements into a campaign.
Whether the GM is designing an entirely new community, adding details to an existing city, or adding
new elements on the fly, the following tables can help better describe and define the next urban
adventure.
