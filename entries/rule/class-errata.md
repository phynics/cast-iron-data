**Sources:** The Elephant in the Room: Feat Taxes in Pathfinder

Errata notes have been provided for all classes presented in the _Pathfinder RPG Core Rulebook,_
save for the barbarian, monk, and rogue. It is suggested that players use the _Pathfinder Unchained_
variations of these classes, which fall more in line with the revised feat tree.
