While engaged in a psychic duel, the combatants don't attack or cast spells normally. Instead, the
combatants create psychic manifestations, abilities that can be used only within a binary mindscape;
these represent changes to the mindscape's fabric (see [Mindscapes](ref/rule/mindscapes)).
