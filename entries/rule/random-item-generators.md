**Sources:** GameMastery Guide pg 118

The following tables allow GMs to randomly generate a wide variety of specific magic items, and
complement the item generation tables [in the base rules](ref/rule/magic-items). Note that these
tables create masterwork versions of armor and weapons; if you want to roll up normal,
non-masterwork items, simply subtract the masterwork cost from the base prices listed. If generated
items prove too powerful (or not powerful enough!) for your PCs' levels, simply roll again!
