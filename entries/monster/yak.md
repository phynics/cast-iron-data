### Description

Per Pathfinder \#51: The Hungry Storm pg. 67, yaks (and [oxen](ref/monster/herd-animal-oxen)) use
[aurochs](ref/monster/herd-animal-aurochs) stats with some modifications. Per Ultimate Equipment pg.
81, yaks use [bison](ref/monster/herd-animal-bison) stats. The stat block above uses the bison
stats.
