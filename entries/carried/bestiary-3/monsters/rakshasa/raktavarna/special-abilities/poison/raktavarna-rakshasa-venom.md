::: statblock
Type: poison
Contracted: injury
Save: Fortitude DC 13
Frequency: 1/round for 6 rounds
Effect: 1d2 Wisdom plus modify memory
Cure: 1 save
:::

Each time a victim takes Wisdom damage from this poison, a modify memory effect causes the victim to
forget the previous minute's interactions with the raktavarna, as long as the raktavarna is no
longer visible or is in object form.
