Below are definitions of some common terms used here.

## Core Class {#core-class}

One of the standard eleven classes found in the _Pathfinder RPG Core Rulebook_.

## Base Class {#base-class}

A class that progresses from level 1–20.

## Caster Level {#caster-level}

Generally equal to the number of class levels (see below) in a spellcasting class. Some prestige
classes add caster levels to an existing class.

## Character Level {#character-level}

The sum of a character's class levels.

## Class Level {#class-level}

The level of a character in a particular class.
