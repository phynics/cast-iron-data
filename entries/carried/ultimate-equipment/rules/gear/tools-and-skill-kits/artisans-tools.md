|Common|5 gp|5 lbs.|
|Masterwork|55 gp|5 lbs.|

::: paragraph statline
These special tools include the items needed to pursue any single craft. Without them, you have to
use improvised tools (–2 penalty on Craft checks), if you can do the job at all.
:::

## Masterwork Artisan's Tools {#masterwork-artisans-tools}

::: paragraph statline
These tools serve the same purpose as artisan's tools, but masterwork artisan's tools are the
perfect tools for the job, so you get a +2 circumstance bonus on Craft checks made with them.
:::
