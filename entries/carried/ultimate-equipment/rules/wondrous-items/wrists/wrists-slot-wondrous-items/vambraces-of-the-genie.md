::: paragraph statline
These bracers are decorated with icons representing air, earth, fire, or water, and depictions of
genies appropriate to that element. The item protects the wearer against hot and cold environments
as if she were using _[endure elements](ref/spell/endure-elements)_ The vambraces' materials and
other powers depend on their associated genie type.
:::

## Djinni {#djinni}

::: paragraph statline
These mithral bracers allow the wearer to use _[gaseous form](ref/spell/gaseous-form)_,
_invisibility_, and _[wind wall](ref/spell/wind-wall)_ each once per day.
:::

## Efreeti {#efreeti}

::: paragraph statline
These scorched bronze bracers allow the wearer to use _invisibility_ (self only),
_[produce flame](ref/spell/produce-flame)_, and _[pyrotechnics](ref/spell/pyrotechnics) _each once
per day.
:::

## Marid {#marid}

::: paragraph statline
These coral bracers allow the wearer to use _[hydraulic torrent](ref/spell/hydraulic-torrent)_,
_invisibility_, and _[water breathing](ref/spell/water-breathing)_ each once per day.
:::

## Shaitan {#shaitan}

::: paragraph statline
These adamantine bracers allow the wearer to use _[glitterdust](ref/spell/glitterdust)_,
_[meld into stone](ref/spell/meld-into-stone)_, and _[stone shape](ref/spell/stone-shape)_ each once
per day.
:::
