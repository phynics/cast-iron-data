You can add spells from another spellcasting class to the spell list of your current spellcasting
class. You add a number of spells equal to 1 + your spellcasting class's key ability score bonus
(Wisdom for clerics, and so on). The spells must be the same type (arcane or divine) as the
spellcasting class you're adding them to. For example, you could add
_[divine power](ref/spell/divine-power)_ to your druid class spell list, but not to your wizard
class spell list because _[divine power](ref/spell/divine-power)_ is a divine spell. These spells do
not have to be spells you can cast as a 1st-level character. The number of spells granted by this
ability is set at 1st level. Changes to your ability score do not change the number of spells
gained. This racial trait replaces shards of the past.
